# Status

Primitives: `div`, `text`, `button`, `text_input` (secure, keyboards, submit), `text_area`, `toggle`, `slider`, `picker`, `date_picker`, `spinner`, `scroll`, `picture`, `shape`, `table` (column widths from content, table semantics for screen readers), `scene3d` (3D), `web_view`, `VirtualList`, `ReorderList`, `screen`, `Router` (stacks, tabs, sheets). Component library `prism::ui`. Accessibility on all backends. Light/dark appearance.
Widgets, Live Activities (Dynamic Island), car screens (CarPlay, Android Auto, Automotive), notifications with actions, remote push (APNs, FCM, Web Push, UnifiedPush) with a server-side sender, background tasks, device APIs (location, motion, photos, camera, haptics, clipboard, share), secure storage, biometrics, Sign in with Apple, OAuth/OIDC sign-in, alerts, context menus, tray and app menus, charts (also in widgets), async tasks, HTTP, storage, i18n/RTL, Dynamic Type, animations, `prism` CLI.
Platforms (supported and preview: see [Platforms in 0.1](introduction.md#platforms-in-01)): web, macOS, iOS/iPadOS, tvOS, watchOS, visionOS, Linux (GTK 4), Android (phones, tablets, Wear OS, Android TV), Windows (WinUI 3 from the Windows App SDK, self-contained: the core kinds as WinUI controls, text fields and rich inputs, web views (WebView2), videos, 3D scenes, links, pointer input and drag and drop, overlays and animations, the system services (pickers, notifications, tray, menu bar, secure storage, Windows Hello), the device APIs (location, motion, the camera, the share sheet, passkeys, haptics), `prism build windows`, UI Automation and the smoke hooks; see [Windows](platforms/windows.md#not-yet) for what comes next).
